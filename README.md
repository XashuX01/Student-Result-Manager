# 🎓 Student Result Manager

A simple Python-based **Student Result Management System** built using basic Python concepts like loops, conditions, dictionaries, and user input handling.

This project helps manage student records directly from the terminal/command line.

---

## 🚀 Features

✅ Add Student Records
✅ View All Students
✅ Check Student Result (PASS / FAIL)
✅ Simple Menu Driven Program
✅ Beginner Friendly Python Project

---

## 🛠️ Technologies Used

* Python 3
* VS Code
* Command Line / Terminal

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/XashuX01/Student-Result-Manager.git
```

### Step 2: Open Project Folder

```bash
cd Student-Result-Manager
```

### Step 3: Run the Program

```bash
python studentResultManager.py
```
